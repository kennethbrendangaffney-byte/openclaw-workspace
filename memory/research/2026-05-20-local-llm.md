## Summary

- **Phi-4 (3.8B) & Qwen2.5 lead 2026 SLM benchmarks** — Microsoft's Phi-4 is winning small-model benchmarks in 2026 despite its 3.8B parameters, outpacing Gemma 3 and Qwen 3 on quality-per-parameter. Qwen2.5 (0.5B–7B range) and Llama 3.2 (1B/3B, designed for edge/mobile) remain the most-used Ollama-compatible models for 8GB RAM setups.

- **llama.cpp CVE-2026-33298: patch now** — A critical integer overflow remote code execution (RCE) vulnerability was disclosed in llama.cpp (CVE-2026-33298, March 2026). Any system running llama.cpp directly or via Ollama should verify they're on a patched build. Separately, community benchmarks confirm llama.cpp runs 1.5–1.8× faster than Ollama on the same hardware for code generation tasks; Ollama bundles a vendored and often outdated llama.cpp revision.

- **GGUF quant ladder: Q4_K_M holds the sweet spot** — For 70B+ models on consumer GPUs in 2026, Q4–Q5 quantization remains the practical ceiling. The annotated variants (Q4_K_M, Q5_K_M, Q6_K) offer meaningfully better quality than their base counterparts at similar file sizes. FP16 is only viable on high-VRAM cards; RTX 3090/4090 still the "pleb standard" for sub-70B models at Q4–Q5 quants. A new guide (KnightLi, April 2026) summarises the quality/speed/VRAM tradeoff ladder as Q8 → Q6 → Q5 → Q4 → Q2.
