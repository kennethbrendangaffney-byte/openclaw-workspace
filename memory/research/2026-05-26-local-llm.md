# Local LLM & Edge AI Research — 2026-05-26

## Summary

- **Ollama v0.30.0-rc15 (May 2026):** Ollama switched back to using llama.cpp as its core inference engine in this release candidate. After diverging to link directly against ggml, the team reverted — citing llama.cpp's continued pace of optimization. For local LLM users this means Ollama inherits those gains (especially for 35B+ models on limited VRAM) while keeping its convenient API layer.

- **Gemma 4 lands with strong local benchmarks:** Google's Gemma 4 (instruction-tuned, Apache 2.0) is getting deep-dive coverage across Ollama, llama.cpp, and vLLM setups. Early benchmarks show it punching above its weight class for a 7B-class model, and the Apache license makes it a solid alternative to Llama for self-hosted deployments.

- **Quantization selection getting clearer:** An April 2026 practical guide (knightli.com) and a "pleb's guide" (d-central.tech) frame the current consensus: Q4_K_M remains the sweet spot for most consumer GPUs; Q8 for quality-critical tasks; Q2 for extreme VRAM savings. llama.cpp's K-quants continue to dominate the local scene, with RTX 3090/4090 still the reference hardware for 70B at Q4-Q5 in 2026.
