# Research Directory

This directory contains automated research from Maxi (MaxClaw Cloud).

## Files
- `YYYY-MM-DD-ai-landscape.md` — Daily AI Landscape Brief
- `YYYY-MM-DD-local-llm.md` — Local LLM & Edge AI
- `YYYY-MM-DD-security.md` — Security Pulse
- `YYYY-MM-DD-academic.md` — Academic Tracker
- `YYYY-MM-DD-openclaw.md` — OpenClaw Ecosystem (weekly)
- `YYYY-MM-DD-career.md` — Career Pathway Scan (weekly)
- `YYYY-MM-DD-hardware.md` — Hardware/Deals Watch (weekly)
- `YYYY-MM-DD-weekly-synthesis.md` — Weekly Synthesis (Sunday)
- `YYYY-MM-DD-passive-income.md` — Passive Income & Automation (bi-weekly)

## Commit Rule
Every research job ends with:
```bash
git add memory/research/ && git commit -m "research: <topic> $(date +%Y-%m-%d)" && git push
```
