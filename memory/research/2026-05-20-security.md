# Security Pulse — 2026-05-20

## Ollama "Bleeding Llama" — CVE-2026-7482 (CRITICAL)
A heap out-of-bounds read in Ollama's GGUF model loader allows unauthenticated remote attackers to leak process memory — API keys, prompts, credentials — via just 3 API calls. 300K+ servers exposed (CVE-2026-7482, May 2026). Also CVE-2026-42248 for Windows RCE. **Patch Ollama to latest version immediately.** This affects local AI setups running Ollama directly.

## Mini Shai-Hulud — npm Supply Chain Worm (Active)
TeamPCP executed a coordinated supply chain attack (Apr 29 – May 1 2026) compromising 84+ npm package artifacts across @tanstack/* and @squawk/* packages. Used GitHub Actions cache poisoning to propagate a worm that steals developer credentials and secrets. Also impacted Bitwarden CLI (fake npm package). **Audit GitHub Actions workflows and npm dependencies.**

## LiteLLM PyPI Compromise — TeamPCP Campaign
Malicious PyPI releases of LiteLLM (widely used in AI proxy/routing stacks) were published March 24/27 2026 as part of the same TeamPCP campaign that hit Telnyx, Trivy, and Axios. Pattern: AI/developer infrastructure is a prime target. **Audit any `pip install litellm` or similar in your environments.**
