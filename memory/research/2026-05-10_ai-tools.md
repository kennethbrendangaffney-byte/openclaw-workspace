## 3. Local / Self-Hosted AI

Local LLMs have moved from "weekend experiment" to daily-driver for many developers. Key benefits: privacy, zero subscription pressure, offline operation, low latency, total control.

### Top 5 Local LLM Tools (2026)

| Tool | Type | Best For | Notes |
|------|------|----------|-------|
| **Ollama** | CLI + API | Default choice — minimal setup, huge model library, cross-platform | `ollama run qwen3:0.6b` — one command |
| **LM Studio** | GUI | Users who prefer a polished desktop experience | Model discovery, visual tuning, API server mode |
| **text-generation-webui** | Browser UI | Power users, customization, extensions | Multiple backends, character presets, RAG workflows |
| **GPT4All** | Desktop app | Beginners | Smooth UI, local chat history, built-in RAG |
| **LocalAI** | API server | Developers | OpenAI API-compatible, Docker-first, multi-runtime |

**Bonus:** **Jan** — full offline ChatGPT-style assistant experience.

### Top Local Models to Run (2026)

| Model | Size | Use Case | Command |
|-------|------|----------|---------|
| **Qwen3** | 0.6B–30B | General tasks, fast | `ollama run qwen3:4b` |
| **Llama 4** | 8B–70B | Most advanced open model | `ollama run llama4:8b` |
| **DeepSeek-V3.2** | 7B+ | Reasoning, coding | `ollama run deepseek-v3.2-exp:7b` |
| **Gemma 3** | 1B–27B | Lightweight, Google | `ollama run gemma3:1b` |

### Hardware Reality Check

- **Entry:** 8GB RAM — small models (Qwen3 0.6B, Gemma3 1B)
- **Comfortable:** 16GB RAM — mid-size models (Llama4 8B, Qwen3 4B)
- **Power user:** 32GB+ RAM — large models, multiple concurrent
- **GPU:** Optional but speeds up larger models significantly

**Ken's note:** Our 24GB RAM puts us in the "comfortable" zone. Current stack (qwen3.5:4b, llama3.1:8b, BitNet 2B) is well-positioned.

## 8. Recommendations for Ken's Setup

Given our hardware (24GB RAM, Linux, no GPU) and goals (local AI development, Trinity/CCT education, entrepreneurial projects):

### Immediate Actions

1. **Stay current on Ollama models** — Qwen3 and Llama4 series are the ones to watch. Test `qwen3:4b` when stable.
2. **Evaluate Claude Code** — For terminal-based coding workflows, especially with our existing Claude Pro subscription.
3. **Monitor Cursor 3.0** — Parallel agents could be useful for multi-file refactoring in our projects.
4. **Keep BitNet running** — 27 t/s at 1.1GB RAM is excellent efficiency. Watch for 8B model fixes.

### Local Stack Opportunities
