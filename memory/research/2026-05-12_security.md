# Security Research Summary — 2026-05-12

## Key Threats (2026)

- **AI-powered attacks** up 47% globally. Attackers use AI for reconnaissance, personalized phishing, and automated malware development. Risky AI prompts increased 97% in 2025; 40% of Model Context Protocols (MCPs) are vulnerable.
- **Ransomware** remains the top threat — 6,604 attacks in 2025 (+52%). Double extortion (steal + encrypt + leak) is standard. Healthcare most targeted (22%).
- **Edge devices** (routers, VPN appliances, gateways) are now prime initial-access targets — often unmonitored and unpatched.
- **Supply chain attacks** continue to scale: one compromised vendor affects thousands.
- **Geopolitical cyber ops** increasingly mirror real-world conflicts, complicating attribution.

## Linux Hardening Priorities

1. **SSH lockdown** — key-based auth only, disable root login, non-standard port, fail2ban/CrowdSec
2. **Automated patching** — unattended-upgrades for security updates
3. **AppArmor/SELinux** — enforce mandatory access controls
4. **Firewall** — UFW or nftables, default-deny, allow only required ports
5. **Container security** — run rootless, scan images, limit capabilities
6. **Audit & monitor** — rsyslog, auditd, AIDE for file integrity

## Self-Hosted Security Stack

| Layer | Tool | Purpose |
|-------|------|---------|
| Perimeter | WG-Easy (WireGuard) | VPN for admin access |
| IPS | CrowdSec + Fail2Ban | Block malicious IPs, share threat intel |
| Secrets | Vault / OpenBao | Centralized encrypted credential storage |
| Passwords | Vaultwarden | Self-hosted Bitwarden (~50MB RAM) |
| DNS | Pi-hole | Block ads/malware at network level |
| SSL | Let's Encrypt | Automated TLS certificates |

## Personal OPSEC

- Use a password manager (Vaultwarden) — unique, strong passwords everywhere
- Enable 2FA on all critical accounts (hardware keys where possible)
- Separate admin and daily-use accounts on all systems
- Keep backups offline/air-gapped — ransomware can't touch what isn't connected
- Review exposed services regularly — `ss -tlnp`, Shodan scan your IP
- Privacy-focused DNS (Mullvad, Quad9) to block malware domains and reduce ISP tracking

## Bottom Line

Defense in depth. No single tool is enough. The cost of a breach (time, data, stress) far exceeds the effort of hardening. Start with CrowdSec + WireGuard + Vaultwarden, then layer from there.
