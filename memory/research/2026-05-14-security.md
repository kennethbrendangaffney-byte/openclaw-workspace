## 3-Bullet Summary

- **🔴 Critical Ollama Memory Leak (CVE-2026-7482):** A heap out-of-bounds read in Ollama's GGUF model loader (fixed in v0.17.1) lets unauthenticated attackers leak process memory — including API keys and credentials — from over **300,000 exposed servers** via just 3 API calls. Patch to v0.17.1+ immediately if running Ollama; restrict network access to localhost if unpatchable. **This directly affects any local Ollama setup on this machine.**

- **⚠️ Mass npm/PyPI Supply Chain Attack (Mini Shai-Hulud Worm):** Over **400 malicious npm packages** and at least **2 PyPI packages** were published in a coordinated campaign targeting TanStack, Mistral AI, and others. The self-propagating worm steals tokens via `postinstall` hooks. Review any recent npm/PyPI installs, audit `package.json`/`requirements.txt`, and revoke any potentially exposed credentials.

- **🟡 OpenClaw Privilege Escalation (CVE-2026-33579 — fixed):** OpenClaw before **2026.3.28** contained a privilege escalation in the `/pair approve` command path that failed to forward caller scopes. If not already updated to a post-March 2026 build, check your current version and upgrade. Also: **Vercel OAuth breach (April 2026)** tied to a third-party AI tool compromise demonstrates the ongoing risk of OAuth token exfiltration via supply chain.
