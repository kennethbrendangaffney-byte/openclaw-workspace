1. **Small models getting surprisingly capable** — 4B–8B dense models now match last year's 30B+ models on many tasks

For Ken's setup (24GB RAM, CPU-only, Linux), the sweet spot remains **3B–4B models at Q4_0 or 1.58-bit quantization**, yielding 2–6× speedups with 70%+ energy reduction.

## 3. BitNet / 1.58-bit Quantization

### Microsoft's bitnet.cpp (Official)
- **Repository:** `microsoft/BitNet`
- **Based on:** llama.cpp framework
- **Speedups:**
  - ARM CPUs: 1.37×–5.07× (larger models = bigger gains)
  - x86 CPUs: **2.37×–6.17×**
- **Energy reduction:** 55%–82%
- **Key claim:** Can run a **100B BitNet model on a single CPU** at human reading speed (5–7 t/s)

### Latest Optimizations (Jan 2026)
- Parallel kernel implementations with configurable tiling
- Embedding quantization support
- **Additional 1.15×–2.1× speedup** over original release

## 6. Quantization Techniques Comparison

| Method | Bits | Size Reduction | Quality Loss | Speedup | Best For |
|--------|------|----------------|--------------|---------|----------|
| FP16 | 16 | 1× | None | Baseline | Training, quality-critical |
| Q8_0 | 8 | 2× | Minimal | ~1.5× | Balanced quality/speed |
| Q4_K_M | 4 | 4× | Low | ~2–3× | General inference |
| Q4_0 | 4 | 4× | Low | ~2–3× | Maximum compatibility |
| Q2_K | 2 | 8× | Moderate | ~4× | Edge, memory-constrained |
| **BitNet I2_S** | **1.58** | **~10×** | **Moderate** | **2–6×** | **Extreme efficiency** |
| **BitNet TL1/TL2** | **1.58** | **~10×** | **Moderate** | **Higher** | **Optimized platforms** |

**Key insight:** BitNet 1.58-bit achieves ~10× size reduction vs FP16. A 7B model becomes ~700MB. This fits in L3 cache on modern CPUs.

## 7. Notable Research & Trends

### DeepSeek-V4 (April 2026)
- **1M token context window**
- MoE architecture: 1.6T total / 49B active (Pro), 284B / 13B active (Flash)
- **Hybrid attention:** Compressed Sparse Attention (CSA) + Heavily Compressed Attention (HCA)
- **KV cache:** Only 2% of standard GQA size
- Designed for **agentic workflows** — preserves reasoning across tool calls

### MLX Ecosystem (Apple Silicon)
- `mlx-lm` enables fast local inference on Apple Silicon
- New "Skill" system for automated model porting from transformers
- Community building tools to bridge transformers → MLX

### CyberSecQwen-4B (May 2026)
- Specialized 4B model for cybersecurity threat intelligence
- Trained on AMD MI300X, Apache 2.0
- **Matches 8B specialist** at half the size
- Demonstrates the power of **domain-specific small models**

### NVIDIA Nemotron 3 Nano Omni (April 2026)
- 30B-A3B MoE with Mamba-Transformer hybrid
- Multimodal: text + image + video + audio
- Long-context document analysis (100+ pages)
- Not for CPU-only, but shows where frontier is heading
