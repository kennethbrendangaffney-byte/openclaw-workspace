## Security Landscape

- ClawHub audit (Apr 23): 10,700+ skills hosted, ~820 malicious ones flagged (7.6%). Use `clawhub verify` before install.
- Supply-chain attack coverage (Skywork AI, May 8) and TCAI risk guide (Apr 1) both published.
- OpenClaw has been actively hardening — plugin manifests narrowed, fail-closed defaults, env-var hardening, removal of `busybox`/`toybox`.
- RCE vulnerability patched in v2026.1.29 (Feb).
- China issued a public security warning linked to OpenClaw (Feb 5).
