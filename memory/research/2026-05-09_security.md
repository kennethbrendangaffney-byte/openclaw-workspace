## 2. Linux Hardening — Practical Steps for Self-Hosted Systems

### Immediate Actions (Do Today)

```bash
# 1. Update everything
sudo apt update && sudo apt upgrade -y

# 2. Enable automatic security updates
sudo apt install unattended-upgrades
sudo dpkg-reconfigure -plow unattended-upgrades

# 3. Check firewall status
sudo ufw status
sudo ufw enable
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 4. Review running services
sudo systemctl list-units --type=service --state=running
sudo ss -tulnp  # See what's listening

# 5. Check for failed login attempts
sudo lastb | head -20
```

### Ubuntu-Specific Hardening

**Built-in protections (verify enabled):**
- **AppArmor:** `sudo aa-status` — should show profiles in enforce mode
- **Unprivileged User Namespace Restrictions:** Default in modern Ubuntu, limits container escape risks
- **Full Disk Encryption:** Verify with `lsblk -f` (look for crypt/fs layers)
- **Secure Boot:** `mokutil --sb-state`

**CIS Benchmarks / DISA-STIG:**
- Ubuntu Pro provides automated compliance scanning
- Free alternative: `lynis` audit tool
  ```bash
  sudo apt install lynis
  sudo lynis audit system
  ```

### SSH Hardening

```bash
# /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no  # Use keys only
MaxAuthTries 3
ClientAliveInterval 300
ClientAliveCountMax 2
AllowUsers yourusername
X11Forwarding no

sudo systemctl restart sshd
```

### Kernel & System Tuning

```bash
# Enable ASLR (should be default)
cat /proc/sys/kernel/randomize_va_space  # Should be 2

# Disable IPv6 if not needed
sudo sysctl -w net.ipv6.conf.all.disable_ipv6=1

# Harden tmp mounts
# Add to /etc/fstab:
# tmpfs /tmp tmpfs defaults,nosuid,nodev,noexec 0 0
```

## 4. Personal OPSEC — Practical Habits

### Digital Hygiene Checklist

- [ ] **Use password manager** — Unique 20+ character passwords everywhere
- [ ] **Enable 2FA** — TOTP or hardware key (YubiKey) on all critical accounts
- [ ] **Separate email tiers** — Critical (banking), social, shopping, throwaway
- [ ] **Freeze credit** — Prevents identity theft (free in most jurisdictions)
- [ ] **Review app permissions** — Phone: disable unnecessary access monthly
- [ ] **Use aliases** — SimpleLogin/AnonAddy for non-critical signups
- [ ] **Encrypt backups** — Restic + rclone to encrypted cloud storage
- [ ] **Verify software** — Check GPG signatures, hashes, reproducible builds

### Threat Model for Self-Hosted Users

**You are likely targeted by:**
1. Automated scanners (constant — SSH brute force, web exploits)
2. Supply chain attacks (compromised dependencies, fake packages)
3. Credential stuffing (reused passwords from breached sites)

**You are less likely targeted by:**
1. Nation-state APTs (unless you're high-profile)
2. Targeted social engineering (varies by visibility)

**Defend accordingly:** Automation + patching > paranoia.

### Red Flags — When to Investigate

```bash
# Check for suspicious activity
sudo ausearch -ts today -k user_logins  # Auditd
sudo journalctl -p err -b  # Boot errors
sudo cat /var/log/auth.log | grep -i "failed\|invalid"  # Auth failures
sudo find /tmp -type f -mtime -1  # Recent temp files
```
