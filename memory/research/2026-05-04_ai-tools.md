## 🚀 Trending This Week

### DeepClaude — Claude Code + DeepSeek V4 Pro
- **What:** Swaps Claude Code's brain to use DeepSeek V4 Pro instead of Anthropic
- **Why it matters:** Same autonomous agent loop, **17x cheaper** ($0.87/M vs $15/M output tokens)
- **GitHub:** `aattaran/deepclaude` — 511+ points on HN
- **Key feature:** Keeps Claude Code's CLI/tool loop (file editing, bash, git, subagents) while routing API calls to DeepSeek
- **Backends:** DeepSeek (default), OpenRouter, Fireworks AI, Anthropic (fallback)
- **Savings:** Light use ~$20/mo vs $200/mo; heavy use ~$50-80/mo
- **Limitations:** No vision input, no MCP servers through compatibility layer

### Claude Code (Anthropic)
- **What:** Agentic coding tool in your terminal — understands codebase, executes tasks, handles git
- **Status:** Now installable via curl script, Homebrew, WinGet (npm deprecated)
- **Cost:** $200/mo with usage caps
- **Features:** File read/write/edit, bash execution, glob/grep, multi-step autonomous loops, subagent spawning, project init (/init)
- **Plugins:** Extensible with custom commands and agents

### Continue Dev — Source-Controlled AI Checks
- **What:** AI-powered code review as GitHub status checks
- **How:** Markdown files in `.continue/checks/` define review rules (security, style, etc.)
- **CLI:** `cn` command — open source, runs agents on every PR
- **Install:** curl script or `npm i -g @continuedev/cli`
- **Also:** VS Code extension available
