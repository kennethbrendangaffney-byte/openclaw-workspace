## 1. Latest Cybersecurity Threats (2026)

### Active Threat Landscape
- **AI-Enhanced Phishing:** LLM-generated spear-phishing with near-perfect grammar and context awareness. Traditional red flags (bad English, generic greetings) no longer reliable.
- **Supply Chain Attacks:** npm, PyPI, and GitHub Actions compromises continue. Typosquatting packages with obfuscated malicious code.
- **Ransomware Evolution:** Double/triple extortion (encrypt + exfiltrate + DDoS + regulatory fines). Linux targets increasing as Windows defences improve.
- **IoT Botnets:** Mirai variants and new families exploiting default credentials in smart home devices. Used for DDoS and proxy networks.
- **Credential Stuffing:** Massive breach databases (billions of credentials) fuel automated account takeover. Password reuse is the #1 enabler.
- **Browser Extension Malware:** Fake extensions mimicking popular tools (VPNs, ad blockers, crypto wallets) stealing cookies/session tokens.
- **Deepfake Social Engineering:** Audio/video impersonation for CEO fraud and family emergency scams. Cost barriers dropping rapidly.

### Linux-Specific Risks
- **Container Escape:** Vulnerabilities in Docker/runc allowing host compromise. Keep runtimes patched.
- **Kernel Privilege Escalation:** Local exploits (e.g., CVE-2024-1086, similar classes in 2025-2026). Unprivileged user → root via kernel bugs.
- **SSH Brute Force:** Constant background noise. Fail2ban essential; key-based auth mandatory.
- **Snap/AppArmor Bypasses:** Sandboxing isn't perfect. Review snap permissions; prefer native packages where possible.
- **Sudo Misconfigurations:** Overly permissive sudoers files. Principle of least privilege.

## 2. Linux Hardening Techniques

### Essential (Do These First)
1. **Keep Updated:** `unattended-upgrades` for security patches. Reboot after kernel updates.
2. **SSH Hardening:**
   - Disable password auth (`PasswordAuthentication no`)
   - Disable root login (`PermitRootLogin no`)
   - Use ed25519 keys only
   - Change default port (security through obscurity + log noise reduction)
   - Install Fail2ban
3. **Firewall:** `ufw` or `nftables`. Default deny, allow only necessary ports.
4. **Automatic Security Updates:** `apt install unattended-upgrades` and configure.
5. **AppArmor/SELinux:** Enforce profiles. Ubuntu defaults to AppArmor; verify it's not in complain mode.

### Intermediate
6. **Kernel Hardening:**
   - `sysctl` tweaks: disable IP source routing, enable SYN cookies, disable IPv6 if unused
   - `kernel.unprivileged_userns_clone=0` (blocks some container escape vectors)
   - `kernel.kptr_restrict=2` (hide kernel pointers)
7. **Filesystem:**
   - Separate partitions for `/tmp`, `/var`, `/home` with `noexec`, `nosuid`, `nodev`
   - Enable `aide` or `tripwire` for integrity monitoring
   - Audit with `auditd`
8. **User Management:**
   - No shared accounts
   - `sudo` timeout reduction (`timestamp_timeout=5`)
   - Lock inactive accounts
9. **Services:**
   - Disable unused services (`systemctl list-unit-files --state=enabled`)
   - Run services as unprivileged users
   - Use `systemd` hardening options (`PrivateTmp=yes`, `NoNewPrivileges=yes`, etc.)
10. **Containers:**
    - Rootless Docker/Podman
    - Read-only root filesystems
    - Drop all capabilities, add back only needed ones
    - User namespaces

### Advanced
11. **Network Segmentation:** VLANs, separate IoT network, firewall rules between segments.
12. **VPN/WireGuard:** All remote access via WireGuard. No direct SSH exposure to internet if possible.
13. **Logging & Monitoring:**
    - Centralised logging (rsyslog to remote server)
    - `logwatch` or `logcheck` for daily summaries
    - File integrity monitoring
14. **Full Disk Encryption:** LUKS for laptops. TPM + PIN for convenience + security.
15. **Secure Boot:** Enable if hardware supports. Prevents bootkit attacks.

## 3. Privacy Tools (Self-Hosted)

### Communication
- **Matrix (Synapse/Dendrite):** Decentralised chat. Self-host for data sovereignty.
- **Jitsi Meet:** Self-hosted video calls. No account needed for participants.
- **Nextcloud Talk:** Integrated with file storage.

### File Storage & Sync
- **Nextcloud:** Full Google Drive/Dropbox replacement. Calendar, contacts, notes, office.
- **Seafile:** Faster than Nextcloud for pure file sync. Less feature-rich.
- **Syncthing:** P2P sync, no central server. Great for device-to-device.

### Password Management
- **Vaultwarden:** Lightweight Bitwarden server. Rust implementation, low resource.
- **KeePassXC:** Offline, local database. No server needed.

### DNS & Network
- **Pi-hole/AdGuard Home:** Network-wide ad/tracker blocking. DNS-level.
- **Unbound:** Recursive DNS resolver. No upstream logging.
- **Mullvad/IVPN/ProtonVPN:** Trustworthy commercial VPNs with Linux clients.

### Search & Browsing
- **SearXNG:** Self-hosted meta-search. Aggregates results without tracking.
- **Firefox + uBlock Origin + Arkenfox user.js:** Hardened browser profile.
- **Tor Browser:** When anonymity matters over convenience.
- **LibreWolf:** Firefox fork with privacy defaults.

### Email
- **ProtonMail / Tutanota:** Encrypted email. Not self-hosted but privacy-respecting.
- **Mail-in-a-Box / Mailcow:** Self-hosted email (high maintenance, deliverability challenges).

### Analytics & Monitoring (Self-Hosted Alternatives)
- **Umami / Plausible / Matomo:** Self-hosted web analytics. Google Analytics alternatives.
- **Uptime Kuma:** Monitoring without third-party services.

## 4. Personal OPSEC (Operational Security)

### Identity Compartmentalisation
- **Separate Personas:** Work, personal, sensitive activities in isolated contexts (different browsers, VMs, or devices).
- **Burner Accounts:** For untrusted services. Unique email (SimpleLogin/AnonAddy), unique password.
- **Phone Numbers:** Use VOIP numbers (e.g., jmp.chat) for non-essential services. Keep real number private.

### Device Security
- **Full Disk Encryption:** Mandatory for laptops. LUKS on Linux, FileVault on Mac, BitLocker on Windows.
- **Automatic Lock:** Short timeout. Require password/PIN on wake.
- **Remote Wipe:** Prey, Find My Device, or similar.
- **Avoid Biometrics for High-Security:** Can be compelled in some jurisdictions. PIN/password has stronger legal protections.

### Communication Hygiene
- **Signal:** Default messenger. Disappearing messages for sensitive content.
- **Verify Safety Numbers:** Always. Man-in-the-middle attacks are real.
- **No Sensitive Comms Over SMS/Email:** These are postcards, not envelopes.
- **Assume All Group Chats Are Leaky:** Even "private" ones.

### Online Presence
- **Minimal Data Exposure:** Lie on security questions. Use fake birthdays where legal.
- **Social Media Lockdown:** Maximum privacy settings. Review tagged photos. Assume employers/future partners will see everything.
- **Google Takeout / Data Downloads:** Regularly download and review what companies have on you.
- **Delete Old Accounts:** Use justdelete.me / directpr.me guides.

### Physical Security
- **Shoulder Surfing:** Privacy screens for laptops in public.
- **USB/Data Ports:** Don't plug unknown USBs. Data blockers for public charging ports.
- **Travel:** Encrypt devices before border crossings. Consider "travel clean" devices for high-risk trips.

### Financial Privacy
- **Privacy.com / Revolut Virtual Cards:** Unique card numbers per merchant. Limits exposure from breaches.
- **Cash:** Still the most private payment method.
- **Monero:** For cryptocurrency privacy needs. Bitcoin is surveillance money.

### Threat Modelling
- **Define Your Threats:** Script kiddy? Ex-partner? Employer? State actor? Your defences should match your threats.
- **Don't Over-Invest:** Perfect security is impossible. Good enough security is achievable.
- **Regular Reviews:** Quarterly audit of accounts, permissions, apps, and data exposure.

## 5. Quick Wins (Do Today)

1. Enable automatic security updates
2. Switch to password manager + unique passwords
3. Enable 2FA everywhere (TOTP/hardware key, not SMS)
4. Review app permissions on phone (location, contacts, camera)
5. Set up Pi-hole or AdGuard Home
6. Switch to Signal for sensitive comms
7. Encrypt laptop disk if not already
8. Review and purge old online accounts
9. Enable Find My Device / remote wipe
10. Set up offline backups (3-2-1 rule: 3 copies, 2 media, 1 offsite)
