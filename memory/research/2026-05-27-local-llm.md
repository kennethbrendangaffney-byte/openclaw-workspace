# Local LLM & Edge AI Update — 2026-05-27

## 3-Bullet Summary

- **Qwen3 dominates local leaderboards**: Qwen3 models (1.5B–14B) are the top-ranked GGUF/llama.cpp models for local use right now, outpacing Llama 3.2 and Gemma 3N in most benchmarks. Phi-4-mini (3.8B) also stands out — performance comparable to 7B–9B models at a fraction of the size.
- **llama.cpp hits 100K GitHub stars, Ollama v0.30.0-rc15 released**: llama.cpp crossed 100,000 stars on GitHub in March 2026 (faster than PyTorch or TensorFlow at the same milestone). Ollama's latest release candidate (v0.30.0-rc15, ~4 days ago) switched back to using llama.cpp as its backend, a notable reversal.
- **Q4_K_M stays the practical sweet spot in 2026**: For sub-70B models at Q4–Q5 quantizations, a single RTX 3090 remains the pleb standard in 2026. The GGUF format ecosystem continues expanding with new quantization suffixes and better quality-per-VRAM trade-offs.
