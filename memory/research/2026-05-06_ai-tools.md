## 🚀 Major Model Releases (May 2026)

### Google Gemma 4 — *Just Released (19 hours ago)*
- **What:** Frontier-level open models from Google DeepMind
- **Sizes:** 2B, 4B, 26B, 31B parameters
- **Capabilities:** Reasoning, agentic workflows, coding, multimodal (vision + audio), tool use
- **Ollama:** `gemma4` tag available — 7M pulls already
- **Significance:** Designed to deliver frontier performance at each size tier. Strong contender for local use at 2B/4B sizes.
- **HN coverage:** Accelerating Gemma 4 with multi-token prediction drafters (593 points)

### GPT-OSS — *OpenAI's Open-Weight Models*
- **What:** OpenAI's first open-weight release
- **Sizes:** 20B, 120B
- **Capabilities:** Reasoning, agentic tasks, developer use cases
- **Ollama:** `gpt-oss` tag — 9.4M pulls
- **License:** Open-weight (check terms for commercial use)
- **Significance:** Major shift for OpenAI — first truly open model release

### Qwen 3.5 — *Alibaba's Latest (1 month ago)*
- **What:** Multimodal open-source models
- **Sizes:** 0.8B, 2B, 4B, 9B, 27B, 35B, 122B
- **Capabilities:** Vision, tools, thinking/reasoning
- **Ollama:** `qwen3.5` tag — 8.6M pulls
- **Note:** This is what Karen currently runs locally (4B variant)

### IBM Granite 4.1 — *Apache 2.0 Licensed*
- **What:** Fully open (Apache 2.0) enterprise-grade LLMs
- **Sizes:** 3B, 8B, 30B
- **License:** Apache 2.0 — truly open for commercial use
- **GGUF available:** Unsloth has quantized variants (1.2GB to 6.34GB)
- **Good for:** Enterprise/local deployments where license clarity matters
