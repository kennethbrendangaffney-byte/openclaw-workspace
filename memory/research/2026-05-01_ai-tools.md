## Coding & Development

### Claude Code
- Terminal-based coding agent from Anthropic
- Reads codebase, plans multi-file changes, writes code, runs tests
- Multi-agent coordination for parallel subtasks
- Now powers GitHub Copilot's enterprise tier
- Works with existing Claude subscription
- **Best for:** Terminal-comfortable devs who want full-project understanding

### Cursor 2.0
- Visual editor with up to 8 parallel AI agents
- Real-time visual review of AI-generated changes
- Bridges design and code
- Pro plan: $20/month
- **Best for:** GUI-preferring devs, teams needing visual review before shipping

### App Builders (No-Code/Low-Code)
- **Lovable** — $20M ARR in 2 months. Natural language → full-stack app with DB, auth, deployment. Fastest-growing AI app builder.
- **Bolt.new** — Rapid prototyping
- **v0 (Vercel)** — React components and UI generation
- **NxCode** — Structured app generation

Running LLMs locally has gone mainstream. Ollama crossed **52 million monthly downloads** in Q1 2026.

### Top Tools

| Tool | Best For | Interface | GPU Required | OpenAI-Compatible API |
|------|----------|-----------|--------------|----------------------|
| **Ollama** | Developers, automation | CLI + REST API | No (helps) | ✅ Yes |
| **LM Studio** | Model evaluation, beginners | Desktop GUI | No (helps) | ✅ Yes |
| **llama.cpp** | Max control & performance | CLI | No (helps) | ✅ Yes (built-in server) |

## Automation & Workflows

Self-hosted automation eliminates per-execution pricing and keeps data local.

| Tool | License | Stars | Integrations | Best For |
|------|---------|-------|-------------|----------|
| **n8n** | Fair-code (Sustainable Use) | 45,000+ | 400+ | Largest community, visual builder + code nodes |
| **ActivePieces** | MIT | 10,000+ | 200+ | Fully open, no restrictions, Zapier-like flow |
| **Windmill** | AGPLv3 | 9,000+ | 100+ (scripts) | Code-first, Rust-built, sub-ms overhead, ETL/data |

## Research & Productivity

### Perplexity Comet
- AI-native browser (not just search)
- Synthesizes real-time web research into cited reports as you browse
- Cross-references multiple live sources
- **Best for:** Competitive research, pre-meeting prep, multi-angle topic understanding
- Pro: $20/month

### NotebookLM (Google)
- Upload documents → AI restricted strictly to those sources (no hallucination)
- Audio Overviews: converts materials into podcast-style dialogue
- Q1 2026 update: interactive mode — interrupt audio, ask follow-ups in real time
- **Best for:** Digesting large document volumes, commute learning

### Gemini in Google Workspace
- Deep integration across Docs, Sheets, Slides, Gmail, Calendar
- Auto-generates formatted docs by synthesizing emails, files, chats, calendar
- Sheets: 70% success rate on complex spreadsheet generation from natural language
- **Best for:** Heavy Google Workspace users
