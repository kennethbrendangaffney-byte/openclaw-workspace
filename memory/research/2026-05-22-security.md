# Security Research — 2026-05-22

## CVE Pulse

- **CVE-2026-7482 (Critical — Ollama Memory Leak):** A single unauthenticated HTTP request to Ollama's `/api/show` or similar endpoints can leak process memory, exposing API keys, prompts, and credentials. Over 300K publicly accessible Ollama servers are affected. Patch to latest version immediately; restrict Ollama to localhost or VPN if unpatched.
- **CVE-2026-42248 (High — Ollama Windows RCE):** Ollama for Windows does not verify the integrity or authenticity of downloaded update executables, enabling remote code execution via a rogue update. Windows users are the primary concern; Linux/Unix deployments are unaffected.

## Auth / Token Incidents

- **Vercel OAuth Supply Chain Breach (April 19, 2026):** Attackers compromised a third-party OAuth integration to access internal systems, including environment variables containing sensitive tokens and secrets. Highlights persistent risk from trusted SaaS integrations — even platforms with strong own security posture can be undone by their OAuth app dependencies.

## Supply Chain Attacks

- **LiteLLM & Telnyx packages poisoned on PyPI (TeamPCP campaign, March 2026):** The `litellm` and `telnyx` packages were hijacked in a Typosquatting/dependency confusion campaign. Four major supply chain attacks targeted Trivy, LiteLLM, Telnyx, and Axios in early 2026 alone.
- **GitHub Actions CI/CD compromise:** Malicious packages on PyPI were used to exfiltrate secrets from CI/CD pipelines running in GitHub Actions, demonstrating the growing pivot from targeting developer machines to targeting build infrastructure.

## Recommendations for This Environment

1. **Ollama** — If running locally, ensure it's bound to `127.0.0.1` only (not `0.0.0.0`). Check `~/.ollama/config.yaml` and verify `host: 127.0.0.1`. Do NOT expose Ollama on a public IP.
2. **Python deps** — Pin exact versions in `requirements.txt` and hash-pinning (`pip hash`) where possible. Verify checksums on high-sensitivity packages.
3. **GitHub Actions / CI secrets** — Review any workflows that pull PyPI packages; consider adding `pip-audit` or `pip-compile` gates.
4. **Vercel / OAuth** — Ken uses Vercel for deployments (noted from project context). Treat any Vercel-issued tokens as high-sensitivity; rotate if not done since April 2026.
