## 🚨 Critical Threats — Immediate Action Required

### 1. Linux "Dirty Frag" Zero-Day (CVE-2026-43284 + CVE-2026-43500)
- **Severity:** CRITICAL — Local root privilege escalation
- **Impact:** All major Linux distributions (Ubuntu, RHEL, CentOS, Fedora, openSUSE)
- **Status:** **NO PATCH AVAILABLE** as of May 8, 2026. Embargo broken May 7.
- **Attack vector:** Chains two kernel page-cache write vulnerabilities (xfrm-ESP + RxRPC). Single command = root.
- **Mitigation (temporary):**
  ```bash
  sh -c "printf 'install esp4 /bin/false\ninstall esp6 /bin/false\ninstall rxrpc /bin/false\n' > /etc/modprobe.d/dirtyfrag.conf; rmmod esp4 esp6 rxrpc 2>/dev/null; true"
  ```
  ⚠️ **Warning:** This breaks IPsec VPNs and AFS network file systems.
- **Source:** [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-linux-dirty-frag-zero-day-with-poc-exploit-gives-root-privileges/)

### 2. Linux "Copy Fail" (CVE-2026-32202) — Now Actively Exploited
- **Severity:** CRITICAL — Local privilege escalation
- **Status:** CISA added to KEV Catalog May 1, 2026. Federal agencies must patch by May 15.
- **Action:** Patch immediately. Check `uname -r` against your distro's security notices.

### 3. Ivanti EPMM Zero-Day (CVE-2026-6973)
- **Severity:** HIGH — Remote code execution
- **Status:** Actively exploited in zero-day attacks. CISA gave federal agencies 4 days to patch (due May 10).
- **Relevance to self-hosters:** If you manage mobile devices or use EPMM, patch now.

### 4. cPanel/WHM Authentication Bypass (CVE-2026-41940)
- **Severity:** CRITICAL — Unauthenticated access to control panel
- **Status:** Known to be used in ransomware campaigns.
- **Relevance:** If you host websites using cPanel, this is a drop-everything patch.

## 🛡️ Linux Hardening — Practical Self-Hosted Checklist

### Immediate Actions (This Weekend)
1. **Patch kernel for Copy Fail (CVE-2026-32202)**
   ```bash
   sudo apt update && sudo apt upgrade linux-image-generic
   sudo reboot
   ```

2. **Apply Dirty Frag mitigation** (until patch available)
   ```bash
   sudo sh -c "printf 'install esp4 /bin/false\ninstall esp6 /bin/false\ninstall rxrpc /bin/false\n' > /etc/modprobe.d/dirtyfrag.conf; rmmod esp4 esp6 rxrpc 2>/dev/null; true"
   ```

3. **Enable automatic security updates**
   ```bash
   sudo apt install unattended-upgrades
   sudo dpkg-reconfigure unattended-upgrades
   ```

### Core Hardening
4. **Firewall — UFW baseline**
   ```bash
   sudo ufw default deny incoming
   sudo ufw default allow outgoing
   sudo ufw allow ssh
   sudo ufw enable
   ```

5. **SSH hardening** (`/etc/ssh/sshd_config`)
   ```
   PermitRootLogin no
   PasswordAuthentication no
   PubkeyAuthentication yes
   MaxAuthTries 3
   ClientAliveInterval 300
   ClientAliveCountMax 2
   ```
   Then: `sudo systemctl restart sshd`

6. **Fail2ban for brute-force protection**
   ```bash
   sudo apt install fail2ban
   sudo systemctl enable fail2ban
   ```

7. **Audit running services**
   ```bash
   sudo ss -tlnp          # listening ports
   sudo systemctl list-units --type=service --state=running
   sudo apt list --installed | wc -l   # package count (aim to minimize)
   ```

8. **Kernel-level protections**
   ```bash
   # Check current settings
   sysctl kernel.randomize_va_space   # Should be 2 (ASLR)
   sysctl kernel.kptr_restrict        # Should be 2
   sysctl kernel.dmesg_restrict       # Should be 1
   
   # Make persistent in /etc/sysctl.d/99-security.conf
   ```

9. **AppArmor/SELinux** — Ensure active
   ```bash
   sudo aa-status          # Ubuntu (AppArmor)
   sudo getenforce         # RHEL (SELinux)
   ```

10. **Disable unused kernel modules** (beyond Dirty Frag)
    Audit `/etc/modprobe.d/` for any modules you don't need (e.g., legacy filesystems, uncommon network protocols).

### Ongoing Maintenance
- **Weekly:** `sudo apt update && sudo apt list --upgradable`
- **Monthly:** Review logs (`/var/log/auth.log`, fail2ban logs)
- **Quarterly:** Audit user accounts, SSH keys, sudoers
- **After major CVEs:** Check CISA KEV Catalog + Ubuntu USN

## 🔒 Privacy Tools & Personal OPSEC (2026)

### Communication
- **Session Messenger** — No phone/email required. Decentralized, routed through Lokinet. Cross-platform.
- **Signal** — Still the gold standard for encrypted messaging. Phone number required but can use secondary number.

### Email
- **StartMail** — Encrypted, unlimited aliases, 10GB storage. Based in Netherlands. Supports custom domains.
- **ProtonMail** — Swiss-based, strong legal protections. Free tier available.

### VPN
- **Surfshark** — Audited by Cure53 (German cybersecurity firm). RAM-only servers. Netherlands-based. Supports unlimited devices.
- **Mullvad** — Anonymous accounts, no email required. Flat pricing. WireGuard support.

### DNS & Tracking Protection
- **NextDNS** — Blocks ads, trackers, malicious domains. 300K queries/month free. Router-level or per-device.
- **Pi-hole** (self-hosted alternative) — Run on your own network. Full control. Pairs well with Unbound for recursive DNS.

### File Storage
- **Internxt** — Anonymous signup, no KYC. E2E encrypted. EU-based servers (France/Germany/Poland). Free 10GB tier.
- **Cryptomator** — Client-side encryption for any cloud storage (Dropbox, Google Drive, etc.). Open source.

### Password Management
- **Bitwarden** (self-hostable via Vaultwarden) — Open source, audited, cross-platform.
- **KeePassXC** — Offline, local database. No cloud dependency.

### Browser
- **Firefox** + **uBlock Origin** + **Privacy Badger** + **HTTPS Everywhere**
- **Tor Browser** — For maximum anonymity (slower, but defeats fingerprinting)
- **Brave** — Chromium-based with built-in ad/tracker blocking. Controversial crypto features can be disabled.

### Search
- **DuckDuckGo** — No tracking. !bang shortcuts for site-specific searches.
- **SearXNG** (self-hosted) — Metasearch engine aggregating multiple sources. No logging.

### Two-Factor Authentication
- **Aegis** (Android) or **Raivo** (iOS) — Open-source TOTP apps. Back up your seeds.
- **Hardware keys:** YubiKey or Nitrokey for high-security accounts.

## 🏠 Self-Hosted Security Architecture

### Network Segmentation
- Isolate IoT devices on separate VLAN/subnet
- Run services in containers (Docker/Podman) with limited capabilities
- Use reverse proxy (Traefik/Nginx Proxy Manager) with automatic HTTPS

### Container Security
```bash
# Run containers as non-root
# Drop all capabilities, add back only what's needed
# Use read-only root filesystems
# Limit resources (CPU/memory)
# Scan images with Trivy or Grype before deployment
```

### Backup Strategy (3-2-1 Rule)
- **3** copies of data
- **2** different media types
- **1** offsite (encrypted)
- Tools: Restic, BorgBackup, Kopia (all support encryption + deduplication)

### Monitoring & Alerting
- **CrowdSec** — Collaborative intrusion detection. Community-driven threat intelligence.
- **Wazuh** (if you want full SIEM) — Open-source XDR/EDR. Heavy but comprehensive.
- **Simple:** Logwatch + custom scripts + Telegram/Discord webhook alerts.
