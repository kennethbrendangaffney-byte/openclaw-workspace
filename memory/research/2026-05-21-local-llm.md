## 3-Bullet Summary

- **Ollama pre-release ditches GGML, links directly to llama.cpp** — A major architectural shift is underway: Ollama's pre-release channel now builds on ggml-org/llama.cpp directly rather than GGML, which should improve GGUF compatibility and let new llama.cpp optimizations (MoE support, Apple Silicon GPU fixes) flow into Ollama automatically. Community benchmarks already show llama.cpp running 1.5–1.8× faster than Ollama on the same hardware.

- **Gemma 4 drops alongside small-SLM landscape maturing** — Google released Gemma 4 (MTP variants: E2B, E4B, 31B, 26B A4B) on April 16, 2026, with strong benchmark numbers. The broader small-LLM ecosystem is consolidating around Qwen2.5 (0.5B–3B), Gemma 3 (1B–27B quantized for mobile), Llama 3.2 (1B/3B, smartphone-ready), and Mistral Nemo 12B as the go-to players in the 1B–8B range.

- **Q4_K_M solidified as the practical quantization sweet spot** — Q4_K_M remains the community-recommended sweet spot (~72% VRAM savings with minimal quality loss). llama.cpp's April 2026 weekly report added a new `--endpoint` CLI option for remote server connections, improving CLI/API usability. Q5_K_M sits just above it for those needing more precision with manageable file sizes.
