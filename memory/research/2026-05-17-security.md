# Security Pulse — 2026-05-17

## CVE & Vulnerability Watch

- **Critical Ollama OOB Read (CVE-2026-7482 / pre-0.17.1):** A critical out-of-bounds read in Ollama allows remote attackers to leak process memory via crafted GGUF files. Over 300,000 exposed servers are at risk — API keys and sensitive data included. Patch to **0.17.1+ immediately** if running Ollama publicly. (The Hacker News, ~7 days ago)
- **36 CVEs in Ollama Go Binary (May 2026):** A recent audit flags 1 CRITICAL + 11 HIGH CVEs in the Ollama binary. If you're on a version prior to latest, treat it as compromised and update. (GitHub #16033, May 7 2026)
- **OpenClaw SSRF (Apr 2026):** An SSRF vulnerability in OpenClaw's Ollama network request handling was disclosed in April 2026 — patch if not already updated.

## Auth & Token Incidents

- **OAuth Token Theft Surge (April 2026):** APT28 hijacked 18,000 routers to steal OAuth tokens; Storm-2372 bypassed MFA without passwords; 28.6M secrets leaked on GitHub. Token-based auth is a primary attack surface this month.
- **Vercel OAuth Supply Chain Breach (April 2026):** A compromised third-party AI tool exploited OAuth permission grants to access Vercel's infrastructure. Anyone relying on Vercel env vars for secrets should rotate them now.

## Supply Chain Attacks

- **Mini Shai-Hulud Worm — npm + PyPI:** Over 160 npm/PyPI packages compromised by a worm that steals secrets (API keys, cloud credentials). Trivy, LiteLLM, Telnyx, Axios all hit in separate early-April campaigns. Check your dependency trees and verify package integrity now.
- **Three-pronged Campaign (Apr 21–23 2026):** npm, PyPI, and Docker Hub all targeted in a 48-hour window — all attacks aimed at exfiltrating secrets. Treat new/unexpected package installs as suspicious.

## Recommendations

1. **Update Ollama** to 0.17.1+ (or latest) — treat pre-0.17.1 as actively vulnerable if exposed.
2. **Rotate any secrets** stored in Ollama env vars, GitHub Actions secrets, or Vercel env vars.
3. **Audit npm/PyPI dependencies** — particularly TanStack, Trivy, LiteLLM, Axios, Telnyx packages.
4. **Review OAuth tokens** — check for unusual grants and rotate any token touched by third-party apps.
