# Security Pulse — 2026-05-21

## CVEs & Vulnerabilities

- **Ollama "Bleeding Llama" (CVE-2026-5757)** — Critical unauthenticated heap memory leak in Ollama allows remote attackers to exfiltrate process memory via crafted GGUF model files. ~300,000 deployments exposed. No patch available yet; mitigations involve network isolation and restricting model upload access. Also CVE-2026-42248 (RCE, Windows) and CVE-2026-7482 (process memory leak) affect Ollama. **Action: if running Ollama, isolate it from untrusted networks and do not accept unauthenticated model uploads.**
- **Supply chain surge (March 2026)** — Five major open-source supply chain attacks in 12 days: Trivy, Checkmarx, LiteLLM (Python AI package — credentials stolen via compromised build), Telnyx, and Axios. LiteLLM attack (Mar 25) is directly relevant to AI workflows. A 73% rise in malicious open-source packages reported for 2026.

## Auth & Token Incidents

- **Vercel breach (Apr 19, 2026)** — Compromise of a Vercel employee's Context.ai account gave attackers OAuth token access, leading to environment variable theft and downstream data exposure. OAuth tokens are flagged as the new primary attack surface for AI platforms. **Action: rotate any tokens ever stored in platform environment variables; treat third-party AI tool access as a risk vector.**

## Summary

Ollama remains the highest-specific risk for this setup — unpatched memory leak affecting 300K+ instances. The LiteLLM and Vercel incidents reinforce that AI ecosystem supply chains (Python packages, OAuth integrations) are active target surfaces. Prioritise network isolation for local Ollama and audit third-party AI tool credentials.
