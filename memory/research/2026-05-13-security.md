## Findings

**OpenClaw RCE Vulnerabilities (CVE-2026-27001 & CVE-2026-25253)**
Two critical CVEs affect OpenClaw: CVE-2026-27001 (pre-2026.2.15) embeds the workspace path unsanitised in the agent system prompt, enabling prompt injection; CVE-2026-25253 allows one-click RCE via authentication token exfiltration exposed through the web interface. Both are actively documented — patch to 2026.2.15+ if not already done.

**PyPI Supply Chain Attacks — LiteLLM and Friends**
March 2026 saw an unprecedented wave of supply chain attacks targeting open-source package ecosystems. LiteLLM on PyPI was compromised (40K+ downloads), enabling remote payload delivery. Chaining with CVE-2026-42248 (Missing Signature Verification for Updates in related packages), attackers achieved reliable remote code execution. Five supply chain incidents were recorded in a 12-day window. If you use LiteLLM or any AI gateway tools, audit your installations immediately.

**Exposed AI Infrastructure — 1M+ Services at Risk**
A May 2026 scan of ~2M hosts found 1M+ exposed AI services (Ollama, LangChain, etc.) due to weak default configurations (no auth, open ports). Simultaneously, CVE-2026-30922 affects Ubuntu's `pyasn1` library (pre-0.6.3) via uncontrolled recursion in ASN.1 decoding, leading to DoS. Also notable: the Vercel breach in April 2026 traced to a Lumma Stealer infection of an AI tool's OAuth application (Context.ai), exposing the OAuth supply chain as a growing attack surface.
