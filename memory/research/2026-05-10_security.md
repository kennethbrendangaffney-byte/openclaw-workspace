## 🔥 Hardware-Level Attacks

### Rowhammer on NVIDIA GPUs (April 2026)
Two independent research teams demonstrated **GDDRHammer** and **GeForge** attacks against NVIDIA Ampere GPUs (RTX 3060, RTX A6000):
- Induce bit flips in GPU memory → corrupt page tables → gain read/write access to **all CPU memory**
- Full system compromise possible
- **IOMMU disabled by default in most BIOS** — this is the critical enabler
- Third variant works **even with IOMMU enabled**

**Mitigation:**
1. Enable IOMMU in BIOS (Intel VT-d / AMD-Vi)
2. Keep GPU drivers updated
3. Physical access is typically required, but shared/cloud GPU environments are higher risk

### DarkSword Exploit Chain (March–May 2026)
- Sophisticated iOS full-chain exploit targeting iOS 18.4–18.7
- Uses **6 zero-day vulnerabilities** across the chain
- Deploys 3 malware families: GHOSTBLADE, GHOSTKNIFE, GHOSTSABER
- Used by multiple commercial surveillance vendors + suspected state actors (Saudi Arabia, Turkey, Malaysia, Ukraine)
- **Leaked publicly** in March 2026 — now in broader use
- Suspected Russian espionage group UNC6353 incorporated it into watering hole campaigns

**Mitigation:** Update iOS immediately. This is exactly why automatic updates matter.

## 🛡️ Linux Hardening — Practical Checklist

### Immediate Actions
- [ ] `sudo apt update && sudo apt upgrade` — apply all pending security updates
- [ ] Enable automatic security updates: `sudo apt install unattended-upgrades`
- [ ] Check for exposed services: `sudo ss -tlnp` — close anything unnecessary
- [ ] Review firewall rules: `sudo ufw status verbose`
- [ ] Audit SSH config (`/etc/ssh/sshd_config`):
  - Disable root login: `PermitRootLogin no`
  - Disable password auth: `PasswordAuthentication no` (if using keys)
  - Change default port (optional, security through obscurity but reduces noise)
  - Use `AllowUsers` or `AllowGroups` to restrict access
- [ ] Check for failed login attempts: `sudo grep "Failed password" /var/log/auth.log | tail -20`

### Medium-Term
- [ ] Install and configure `fail2ban` for SSH and other services
- [ ] Enable AppArmor or SELinux (Ubuntu uses AppArmor by default — verify it's enforcing)
- [ ] Set up `lynis` security audit: `sudo apt install lynis && sudo lynis audit system`
- [ ] Review systemd services: `systemctl list-units --type=service --state=running` — disable unused
- [ ] Kernel hardening via `sysctl`:
  - `kernel.kptr_restrict=2` — hide kernel pointers
  - `kernel.dmesg_restrict=1` — restrict dmesg access
  - `fs.protected_hardlinks=1` / `fs.protected_symlinks=1`
- [ ] Consider `firejail` for sandboxing untrusted applications
- [ ] Enable full-disk encryption if not already (check `lsblk -f` for crypto flags)

### Advanced
- [ ] Review and minimize SUID binaries: `find / -perm -4000 -type f 2>/dev/null`
- [ ] Set up AIDE or Tripwire for file integrity monitoring
- [ ] Consider `grub` password protection
- [ ] Audit cron jobs: `sudo find /etc/cron* -type f -exec ls -la {} \;`
- [ ] Check for hidden reverse shells: `sudo netstat -tulpn | grep -v "127.0.0.1"`

## 🕵️ Personal OPSEC — Practical Tips

### Device Hygiene
1. **Automatic updates on everything** — phones, laptops, routers, IoT
2. **Separate work/personal devices** if possible (or at least user accounts)
3. **Disable Bluetooth/WiFi when not needed** — reduces attack surface
4. **Cover cameras** when not in use (paranoid but zero-cost)
5. **Use a password manager** — unique passwords everywhere. Bitwarden/Vaultwarden recommended.

### Communication
1. **Signal for sensitive comms** — EFF-endorsed, open source, E2EE by default
2. **Avoid SMS for 2FA** — use authenticator apps (Aegis on Android, Tofu on iOS) or hardware keys (YubiKey)
3. **Be wary of "urgent" messages** — phishing is still #1 attack vector

### Online Identity
1. **Use unique emails per service** — SimpleLogin/AnonAddy (or self-host with wildcard aliases)
2. **Minimize data sharing** — every service you sign up for is a future breach
3. **Review app permissions regularly** — phone and browser extensions
4. **Use separate browser profiles** — work, personal, banking, shopping

### Financial
1. **Virtual cards** where available — limit exposure if merchant breached
2. **Monitor bank statements** — set up alerts for all transactions
3. **Credit freeze** — in countries that support it, prevents identity theft loans

### Travel / Public WiFi
1. **Always use VPN on public WiFi** — WireGuard/Tailscale
2. **Forget networks after use** — prevents auto-reconnect to evil twins
3. **Disable auto-connect to open networks**
