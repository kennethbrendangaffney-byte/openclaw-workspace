## 🧑‍💻 AI Coding & Development Tools

The landscape consolidated around three major platforms in 2026, with strong open-source alternatives.

### Major Platforms

| Tool | Strength | Pricing | Free Tier | Best For |
|------|----------|---------|-----------|----------|
| **Cursor 3.1** | Agent workspace, multi-model, voice input | $20/mo Pro | Yes (limited) | Solo & team developers |

**Cursor 3.1** — Now an "agent workspace" with tiled multi-agent layout, voice input, and Bugbot (78% bug resolution rate). SpaceX inked a $10B deal — signal that it's enterprise-grade. Multi-model support: Claude Opus 4.7, GPT-5.5, Gemini 2.5, open-weights.

**GitHub Copilot /fleet** — Multi-agent CLI orchestration. "Rubber Duck" pairs AI models for cross-review. Note: Pro signups were paused mid-2026 and Opus models removed due to capacity constraints.

**Claude Code** — Best for terminal-native devs. Claude Opus 4.7's million-token context window. Anthropic launched "Managed Agents" for hosted production workflows.

## 🏠 Local & Self-Hosted LLM Tools

Local LLMs moved from "weekend experiment" to practical daily setup in 2026.

### Top 5 Local LLM Tools

| Tool | Best For | Key Feature |
|------|----------|-------------|
| **Ollama** | Fastest setup | One-line CLI, huge model library, API server |
| **LM Studio** | GUI users | Polished desktop experience, model discovery |
| **text-generation-webui** | Customizers | Multiple backends, extensions, RAG workflows |
| **GPT4All** | Beginners | Desktop-first, local RAG, simple settings |
| **LocalAI** | Developers | OpenAI API-compatible, Docker-first |

**Bonus:** **Jan** — Full offline ChatGPT-style assistant experience.

### Notable Local Models (2026)

- **Llama 5** — Released April 8, 2026
- **Qwen 3.5** series — Increasingly capable, multiple sizes
- **DeepSeek-V3.2** — Reasoning models, efficient
- **Gemma 3** — Google's lightweight series (1B good for small hardware)
- **Llama 4** — 8B size, advanced open model

### Why Local in 2026?

1. Complete data privacy — no third-party servers
2. Zero subscription pressure — cost-effective for heavy use
3. Offline operation — travel, restricted networks, secure environments
4. Low latency — no network round-trip
5. Total control — select models, switch quantizations, tune parameters

## 🎯 Key Trends for 2026

1. **Agent-first workflows** — Tools are becoming agent workspaces, not just completion engines
2. **Multi-model flexibility** — Best tools let you switch models per task
3. **Local = viable** — Open models now rival cloud for many tasks, especially with 4-bit quantization
4. **Voice input** — Becoming standard in coding tools (Cursor 3.1, etc.)
5. **Design-to-code** — GLM-5V-Turbo (94.8 benchmark), Qwen3.6-Plus for wireframe-to-app
6. **Self-hosting resurgence** — Privacy concerns + cost driving local deployment
7. **Vibe coding** — Lovable, Bolt, v0 for building apps from prompts without traditional coding
