# Security Research — 2026-05-15

## CVEs: Critical Ollama Flaw (CVE-2026-7482)
- **Critical OOB read in Ollama < 0.17.1** exposes process memory — including API keys — on **300K+ servers** via crafted GGUF files. Patch to 0.17.1 immediately. ([The Hacker News](https://thehackernews.com/2026/05/ollama-out-of-bounds-read-vulnerability.html), [Indusface](https://www.indusface.com/blog/cve-2026-7482-bleeding-llama-vulnerability/))
- Also covered: critical bugs in Langflow, SonicWall SonicOS, and n8n flagged in April TPRM analysis.

## Supply Chain: npm/PyPI Mass Compromise
- **Hundreds of npm + PyPI packages** compromised in a large-scale supply chain attack, stealing developer credentials and wiping data. Affected includes `@tanstack/react-router`, `@mistralai/mistralai`, `@opensearch-project/opensearch`, and UiPath packages. ([NHS Digital Alert](https://digital.nhs.uk/cyber-alerts/2026/cc-4781), [CyberNews](https://cybernews.com/security/npm-packages-with-millions-downloads-compromised/))
- Separately: a **self-propagating npm worm** using postinstall hooks to steal tokens hit 6 packages in April. ([The Hacker News](https://thehackernews.com/2026/04/self-propagating-supply-chain-worm.html))

## Auth/Tokens: OAuth Long-Lived Token Risk
- OAuth tokens without expiry enabling breach sprawl — the **Drift attack hit 700+ firms**, bypassing MFA via tokens. ([The Hacker News](https://thehackernews.com/2026/05/the-back-door-attackers-know-about-and.html))
- **Vercel April breach**: third-party AI tool's compromised Google Workspace OAuth app was the entry point. ([Trend Micro](https://www.trendmicro.com/en_us/research/26/d/vercel-breach-oauth-supply-chain.html))

## Action Items
- **Patch Ollama to >= 0.17.1 now** if running locally (Karen: check `ollama --version`)
- Audit npm/PyPI deps for compromised packages listed above
- Review long-lived OAuth tokens in any connected integrations
