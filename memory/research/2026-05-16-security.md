## 🔴 Critical: Ollama Memory Leak — CVE-2026-7482
- **Severity:** Critical (CVSS ~9.0)
- **Affected:** Ollama < 0.17.1 (300,000+ exposed servers)
- **Vulnerability:** Heap out-of-bounds read in GGUF model loader (`/api/create` endpoint)
- **Impact:** Unauthenticated attackers leak process memory — including API keys, prompts, and credentials — via a crafted GGUF file in 3 API requests
- **Status:** Patch available (≥ 0.17.1). If running Ollama, upgrade immediately; do not expose the `/api/create` endpoint publicly
- **Also affects:** Ubuntu users with snap/apt Ollama packages — verify version, not just presence

## 🟠 Supply Chain: Mini Shai-Hulud Worm — TanStack + 170+ npm/PyPI Packages
- **Severity:** High
- **Packages hit:** TanStack Router (@tanstack/react-router), Mistral AI SDK (@mistralai/mistralai), OpenSearch, UiPath, and 160+ others on npm and PyPI
- **Attack vector:** GitHub Actions `pull_request_target` + cache poisoning across fork↔base trust boundary (same family as the Shai-Hulud campaign)
- **Impact:** CI/CD environments running `npm install`/`pip install` on affected packages risk credentialtheft and repo compromise
- **Action:** Pin dependencies to known-good versions; audit lockfiles; delay auto-update of TanStack and related packages
