# Local LLM Research — 2026-05-12

## Key Trends

**Small models are closing the gap.** Epoch AI research shows compute required for equivalent accuracy halves every ~8 months. A 3.8B model today can match what 70B did in 2024. The focus has shifted from "bigger is better" to "intelligence density" — per-parameter efficiency matters more than raw scale.

**SLMs are production-ready.** Gartner predicts organizations will use task-specific small language models (SLMs) 3× more than general LLMs by 2027. They run on 8GB VRAM GPUs, mobile NPUs, and edge devices. Inference costs drop to near-zero locally vs. $3–15 per million tokens for cloud APIs.

## Quantization

**Q4_K_M** remains the sweet spot — ~50–75% size reduction with minimal quality loss. INT8/INT4 widely supported for edge deployment. llama.cpp v0.90+ handles most formats natively.

**BitNet (1.58-bit ternary)** is the radical outlier. Microsoft’s bitnet.cpp achieves:
- 1.37–6.17× speedup on CPU (ARM and x86)
- 55–82% energy reduction
- 100B parameter models runnable on a single CPU at human reading speed (5–7 tok/s)
- Weights constrained to {-1, 0, +1}, replacing floating-point ops with integer additions

Current practical limit for BitNet: 2B models work reliably; 8B+ requires kernel rebuilds and has conversion issues.

## Inference Frameworks

- **llama.cpp** — v0.90+, the gold standard for CPU/GPU inference. Broad quantization support, active development.
- **Ollama** — single-command deployment (`ollama pull model:tag`). Best for getting started quickly.
- **bitnet.cpp** — Microsoft’s official 1-bit inference stack. CPU-optimized, GPU kernels available, NPU support planned.

## Hardware Reality Check

- **7B models:** 8GB VRAM minimum, or 32GB+ system RAM for CPU
- **13B models:** 12–16GB VRAM
- **70B+ models:** 48GB+ VRAM, or CPU offloading with 64GB+ fast DDR5
- **Budget build:** $500–700 can run 7B–13B at usable speeds
- **Apple Silicon:** Unified memory makes Macs surprisingly competitive for local inference

## Bottom Line

For Ken’s 24GB RAM Linux box: 3B–8B quantized models (Q4_K_M) are the practical sweet spot. BitNet 2B works now and is worth watching as larger variants mature. Phi-4-mini and Qwen3-4B are the top candidates to evaluate next.
