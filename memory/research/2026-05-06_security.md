## Linux Hardening Priorities

### Immediate Actions for Ubuntu/Debian Systems

1. **Kernel Updates**
   - CVE-2026-31431 affects current kernels
   - Run: `sudo apt update && sudo apt upgrade linux-image-generic`
   - Reboot required after kernel updates

2. **SSH Hardening**
   - Disable root login: `PermitRootLogin no` in `/etc/ssh/sshd_config`
   - Use key-based auth only, disable password auth
   - Change default port (security through obscurity + log noise reduction)
   - Install fail2ban: `sudo apt install fail2ban`

3. **Firewall Configuration**
   - Enable UFW: `sudo ufw enable`
   - Default deny: `sudo ufw default deny incoming`
   - Allow only necessary ports
   - Rate limit SSH: `sudo ufw limit ssh`

4. **AppArmor**
   - Ensure AppArmor is enforcing: `sudo aa-status`
   - Most Ubuntu systems have it enabled by default
   - Check profiles are loaded for critical services

5. **Automatic Updates**
   - Install unattended-upgrades: `sudo apt install unattended-upgrades`
   - Enable security updates only to avoid breakage
   - Configure: `sudo dpkg-reconfigure unattended-upgrades`

6. **User Management**
   - Remove unnecessary users
   - Enforce strong passwords: `sudo apt install libpam-pwquality`
   - Configure password policies in `/etc/security/pwquality.conf`
   - Use sudo with timeout: `Defaults timestamp_timeout=5` in `/etc/sudoers`

### Advanced Hardening

7. **Disk Encryption**
   - LUKS for full disk encryption (already standard on Ubuntu installs)
   - Consider TPM-backed decryption with Clevis for servers

8. **Secure Boot**
   - Ensure Secure Boot is enabled in UEFI
   - Verify: `mokutil --sb-state`

9. **Kernel Parameters**
   - Add to `/etc/sysctl.conf`:
     ```
     kernel.dmesg_restrict = 1
     kernel.kptr_restrict = 2
     kernel.yama.ptrace_scope = 1
     fs.suid_dumpable = 0
     ```
   - Apply: `sudo sysctl -p`

10. **Audit Logging**
    - Install auditd: `sudo apt install auditd`
    - Monitor critical files and system calls
    - Forward logs to centralized system if available

## Privacy & OPSEC Tools (Self-Hosted)

### Password Management
- **Vaultwarden** (Bitwarden RS) - Self-hosted password manager
  - Lightweight Rust implementation of Bitwarden server
  - Docker deployment available
  - E2EE - server cannot decrypt your vault

### VPN/Network Privacy
- **WireGuard** - Modern, fast VPN protocol
  - Native in Ubuntu 20.04+ kernel
  - Much simpler than OpenVPN
  - Self-hosted server option
- **Mullvad VPN** - Privacy-focused commercial option (no accounts, cash payments)

### Communication
- **Signal** - E2EE messaging (mobile + desktop)
- **SimpleX Chat** - No user identifiers, decentralized
- **Session** - Anonymous, decentralized, no phone number required

### Browser Privacy
- **Firefox** with privacy tweaks (about:config)
- **Brave** - Built-in ad/tracker blocking
- **Tor Browser** - For anonymity-critical activities
- **uBlock Origin** - Essential ad/tracker blocker

### DNS Privacy
- **Pi-hole** - Network-level ad blocking (self-hosted)
- **Unbound** - Recursive DNS resolver (no third-party DNS)
- **DNS-over-HTTPS (DoH)** or **DNS-over-TLS (DoT)** to prevent ISP snooping

### File Storage
- **Nextcloud** - Self-hosted cloud (files, calendar, contacts)
- **Syncthing** - P2P file sync (no central server)
- **Cryptomator** - Client-side encryption for cloud storage

## Threat Model for Personal Use

### Common Threats to Address

1. **Passive Attacks** (malware, data breaches)
   - Keep software updated
   - Use reputable sources only
   - Enable automatic security updates

2. **Surveillance Capitalism** (Google, Facebook tracking)
   - Use privacy-focused alternatives
   - Block trackers at browser and network level
   - Minimize data sharing

3. **Mass Surveillance**
   - Use E2EE communication tools
   - Consider VPN for everyday browsing
   - Be mindful of metadata

4. **Targeted Attacks** (if you're high-profile)
   - Use Qubes OS or similar compartmentalization
   - Separate devices for different risk levels
   - Hardware security keys (YubiKey, Nitrokey)

### Security by Compartmentalization

- **Virtual machines** for different activities
- **Separate browsers** for different identities
- **Different email addresses** for different purposes
- **Qubes OS** for maximum isolation (if threat model warrants)
