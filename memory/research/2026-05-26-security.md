# Security Pulse — 2026-05-26

## Findings

### 🔴 OpenClaw (Critical — multiple CVEs active)
- **CVE-2026-32922** (Critical): Privilege escalation to admin + RCE in OpenClaw — patch immediately if on a affected version.
- **CVE-2026-33579** (Critical): `/pair approve` endpoint vulnerability — allows unauthorized pairing/access.
- **CVE-2026-27001** (High): Workspace path embedded in agent prompts pre-2026.2.15 — potential information disclosure.
- **Cyera research (May 15 2026)**: Four chainable vulnerabilities discovered including a **9.6 CVSS** sandbox escape affecting 180K+ OpenClaw deployments.

### 🟡 Ollama
- **CVE-2026-42248** (RCE, Windows): Remote code execution in Ollama for Windows — April 30 2026.
- **36 vulnerabilities** reported in Ollama Go binary (1 CRITICAL, 11 HIGH, 23 MEDIUM) — GitHub issue #16033, May 7 2026. Check if local install is affected.

### 🟠 Supply Chain (PyPI/npm — TeamPCP campaign still active)
- **38% surge** in Q1 2026 supply chain attacks across npm, PyPI, Maven, Homebrew.
- **TeamPCP campaign** (ongoing since March 2026): Compromised LiteLLM and Telnyx on PyPI; escalated May 11 2026 with new npm+PyPI attacks.
- **April 21–23 wave**: Three attacks in 48hrs targeting API keys and cloud credentials across npm, PyPI, and Docker Hub.
- **Confirmed targets**: Trivy, Checkmarx, LiteLLM, Telnyx, Axios.

### 🟡 Python / Auth
- **PyJWT accept flaw** (UBUNTU-CVE-2026-32597): Accepts tokens with unrecognized `crit` extensions instead of rejecting — enables auth bypass.
- **python-dotenv** (CVE-2026-28684, <1.2.2): reading `.env` files can overwrite arbitrary environment variables.
- **urllib3 DoS** (CVE-2026-21441): Ubuntu-7839 related resource exhaustion.

## Actions Recommended
- [ ] **OpenClaw**: Update to latest version (≥2026.2.15), review `/pair approve` config.
- [ ] **Ollama**: Review GitHub issue #16033 for patch status, disable Windows RCE surface if unused.
- [ ] **Supply chain**: Pin package versions in requirements.txt, enable audit logging on installs.
- [ ] **PyJWT**: Ensure version ≥2.x with proper crit extension handling.
- [ ] **python-dotenv**: Upgrade to ≥1.2.2.
