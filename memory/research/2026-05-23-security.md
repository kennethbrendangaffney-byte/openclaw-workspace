## Bullet Summary
- **CVE-2026-7482 "Bleeding Llama"** — Critical unauthenticated memory-leak in Ollama allows remote attackers to extract API keys, prompts, and credentials via just 3 API calls; 300K+ public instances exposed. Patch to latest Ollama version immediately if running a public instance.
- **CVE-2026-28480** — OpenClaw versions before 2026.2.14 had an authorization bypass: Telegram allowlist matching accepted mutable usernames, allowing an attacker to impersonate an allowed user. Patched; verify you are on 2026.2.14 or later.
- **Supply chain surge (Apr–May 2026)** — Three npm/PyPI/Docker Hub campaigns in 48 hours (GitGuardian, Apr 23), and the "Mini Shai-Hulud" campaign (Arctic Wolf, May 11) using GitHub Actions cache poisoning; 170+ malicious packages across TanStack and related ecosystems. Review CI/CD pipeline dependencies and avoid auto-installing untrusted updates.
